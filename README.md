# 🧟 僵尸防线 · 至尊版

一个纯前端单文件 Canvas 塔防割草小游戏：竖屏守防线 + 自动开炮 + 升级三选一 + 局外养成 + 模拟充值。

> 玩法机制致敬经典"守防线割草"品类，所有美术（Canvas 手绘）、数值、代码均为原创，无任何第三方游戏资源。

## 在线试玩

- WorkBuddy 托管：https://zombie-defense-10911.app.workbuddy.host/
- GitHub Pages：开启后为 `https://yang1996202-cpu.github.io/zombie-defense/`

## 玩法

- 左右拖动移动炮台，自动锁定开炮
- 僵尸波次递增：普通 / 疾跑 / 坦克，每 5 波 Boss（会远程吐弹）
- 升级三选一，14 种技能：火力强化 / 多弹道 / 穿甲 / 爆破 / 冰冻 / 无人机 / 制导激光 / 燃烧 / 雷电链 / 弹幕风暴 / 处决令……
- 局外养成循环：
  - 💰 金币 → 军备研究所（4 条永久升级线）
  - 💎 钻石 → 至尊宝箱抽宝石（6 种宝石 × 传说/绝世/至尊三品质，全局自动生效）
  - 充值中心为**模拟支付**（0 元真实扣费），首充双倍 + VIP 加成，纯还原付费手感
- x1/x2/x3 倍速、暂停、战斗中结算回基地，进度 localStorage 自动存档

## 运行

无依赖、无构建，任选其一：

```bash
# 直接双击 index.html 用浏览器打开
# 或起个本地服务
python3 -m http.server 8080
```

## 技术要点

- 单 HTML 文件，Canvas 2D，零依赖
- 追踪弹（发射锁定目标 + 飞行中转向）
- 离屏预渲染背景、DOM 覆盖层签名守卫（防 60fps 重建导致按钮失效）
- 局外成长数据 localStorage 持久化
